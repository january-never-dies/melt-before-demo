# Melt Before — English Portfolio Demo

An API-free interactive recreation of the Apps-in-Toss miniapp **Melt Before**.

The demo lets reviewers experience the complete core flow:

1. Choose a cone or ice bar.
2. Select a sample destination.
3. Compare walking time with the recommended arrival time.
4. Watch the 3D ice cream change during an accelerated journey.
5. Review the result and the summer freezer collection.

## Privacy and API policy

This portfolio build does not request location permission and does not call TMAP, Korea Meteorological Administration, or Apps-in-Toss APIs. Weather, places, and routes are representative sample data.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/` and can be hosted on GitHub Pages.
